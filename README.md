# Exercício 24 - Estrutura While

## Descrição

O programa solicita ao usuário uma frase e um número inteiro. Em seguida, utiliza a estrutura de repetição `while` para exibir a frase o número de vezes informado pelo usuário.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

O programa solicita ao usuário uma frase e um número inteiro que representa a quantidade de vezes que a frase deve ser exibida.

## Saída

O programa exibe a frase informada pelo usuário a quantidade de vezes especificada.
